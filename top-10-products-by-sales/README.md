# Top 10 Products by Sales

## Project Overview
This project identifies the top 10 products based on total sales using the Superstore dataset.

## Objective
To analyze product-level sales and identify the products generating the highest sales.

## Tools Used
- Microsoft Excel
- Python
- Pandas
- Matplotlib

## Methodology
1. Loaded the Superstore sales data.
2. Calculated total sales for each product.
3. Sorted products by sales in descending order.
4. Identified the top 10 products.
5. Created a bar chart to visualize the results.
6. Checked the Top 10 cutoff for ties.

## Deliverables
- Top 10 products by sales table
- Excel analysis
- Sales visualization
- Python analysis and chart

## Result
The analysis identified the 10 products with the highest total sales in the dataset.

## Conclusion
The project demonstrates how Excel and Python can be used to analyze sales data, rank products, and communicate findings through visualization.

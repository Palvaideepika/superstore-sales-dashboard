# Region Performance Analysis

## Overview

This project analyzes sales and profit performance across different regions using the Superstore dataset.

## Objective

- Compare sales across regions
- Compare regional profit
- Rank regions based on sales
- Create visual reports using Excel and Power BI

## Tools Used

- Microsoft Excel
- Power BI
- Superstore Dataset

## Analysis Performed

### Region Summary

The analysis summarizes total Sales and Profit for:

- Central
- East
- South
- West

### Sales Ranking

Regions were ranked based on total sales.

1. West
2. East
3. Central
4. South

## Visualizations

### Excel

- Region Summary
- Sales by Region bar chart
- Regional Sales and Profit comparison

### Power BI

- Region Summary table
- Sales by Region bar chart
- Regional Sales and Profit Comparison dashboard

## Key Results

| Region | Sales | Profit |
|---|---:|---:|
| West | 725457.82 | 108418.45 |
| East | 678781.24 | 91522.78 |
| Central | 501239.89 | 39706.36 |
| South | 391721.91 | 46749.43 |

## Conclusion

The analysis provides a comparison of regional sales and profit performance and demonstrates the use of Excel PivotTables, charts, and Power BI visualizations for regional business analysis.

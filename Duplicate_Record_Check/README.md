# Duplicate Record Check – Sample Superstore

## Objective

The objective of this task was to identify duplicate records in the Sample Superstore dataset and prepare a cleaned copy of the data.

## Dataset

The dataset used for this task is the Sample Superstore dataset containing sales-related information such as:

- Order ID
- Order Date
- Customer ID
- Customer Name
- Region
- Product ID
- Category
- Sales
- Quantity
- Discount
- Profit

## Duplicate Check Process

The duplicate check was performed in Microsoft Excel using the **Remove Duplicates** feature.

All available columns were selected so that a record was considered a duplicate only when the complete row contained the same values.

## Results

- Duplicate records found: **0**
- Duplicate records removed: **0**
- Status: **No duplicate records found**

Since no exact duplicate records were identified, no records were removed from the cleaned dataset.

## Files

- `Duplicate_Record_Check.xlsx` – Excel workbook containing the original data, cleaned data, and duplicate check report.
- `README.md` – Documentation of the task and results.

## Tools Used

- Microsoft Excel
- GitHub

## Conclusion

The Sample Superstore dataset was checked for complete duplicate records. The analysis found **no duplicate records**, so the cleaned dataset remains unchanged from the original dataset.

# Customer Order Count Analysis

## Project Overview

This project analyzes customer purchasing activity using Excel. The main objective is to identify how many orders each customer placed and find the top 10 customers based on order count.

## Objectives

* Count orders for each customer.
* Identify the top 10 customers by order count.
* Compare customer purchasing activity.
* Visualize the results using a bar chart.

## Tools Used

* Microsoft Excel
* PivotTables
* PivotCharts

## Project Steps

1. Selected the customer and order data from the dataset.
2. Created a PivotTable using Customer ID and Order ID.
3. Counted orders for each customer.
4. Sorted customers by order count in descending order.
5. Applied a Top 10 filter to identify frequent buyers.
6. Created a clustered bar chart to visualize the results.

## Key Insights

* The PivotTable summarizes order counts for individual customers.
* The Top 10 filter highlights customers with the highest order counts.
* The bar chart makes it easier to compare customer order frequency.

## Files Included

* `Customer_Order_Count_Analysis.xlsx` — Excel analysis containing the PivotTable and chart.

## Conclusion

This analysis demonstrates how Excel PivotTables and PivotCharts can be used to summarize customer order activity, identify frequent buyers, and present findings in a clear visual format.

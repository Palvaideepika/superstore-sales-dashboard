# Monthly Sales Trend

## Project Overview

This project analyzes monthly sales data from the Sample Superstore dataset using Microsoft Excel.

## Objective

- Summarize sales by month
- Practice date handling and monthly grouping
- Analyze sales trends over time
- Create a line chart to visualize monthly sales

## Tools Used

- Microsoft Excel
- PivotTable
- Line Chart

## Dataset

Sample Superstore dataset.

## Process

1. Prepared the Order Date data.
2. Created a Month-Year field.
3. Created a PivotTable to calculate monthly sales.
4. Sorted the months chronologically.
5. Created a Monthly Sales Trend line chart.

## Deliverables

- Monthly sales table
- Monthly Sales Trend line chart
- Excel analysis file

## Key Learning

This project helped me practice date handling, PivotTables, sales aggregation, chronological sorting, and data visualization in Excel.

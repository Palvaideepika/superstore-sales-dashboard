# Simple Profit Analysis

## Project Overview

This project analyzes profit performance across different product categories using the Sample Superstore dataset.

The analysis was performed in Microsoft Excel to calculate total profit and average profit for each product category and visualize the results using a column chart.

## Objectives

- Analyze profit by product category
- Calculate total profit for each category
- Calculate average profit for each category
- Compare profitability across categories
- Create a visual chart to present the results

## Dataset

The analysis uses the Sample Superstore dataset containing sales transaction information, including category and profit details.

## Tools Used

- Microsoft Excel
- Excel formulas
- SUMIF
- AVERAGEIF
- Column Chart

## Analysis Performed

The following categories were analyzed:

- Furniture
- Office Supplies
- Technology

### Total Profit

| Category | Total Profit |
|---|---:|
| Furniture | 18,451.27 |
| Office Supplies | 122,490.80 |
| Technology | 145,454.95 |

Average profit was also calculated for each category using the `AVERAGEIF` function.

## Visualization

A **Total Profit by Category** column chart was created to compare the profit generated by Furniture, Office Supplies, and Technology.

## Key Learning

This task provided practical experience in:

- Excel-based data analysis
- Conditional calculations
- Profit comparison
- Data summarization
- Creating business-oriented visualizations
- Presenting analytical findings clearly

## Conclusion

The analysis summarizes category-level profitability from the Superstore dataset and demonstrates how Excel can be used to transform raw business data into meaningful insights and visual reports.

# Basic Sales Summary – Sample Superstore

## Objective

The objective of this task was to create a basic sales summary from the Sample Superstore dataset using Microsoft Excel.

## KPIs Calculated

The following key performance indicators were calculated:

1. Total Sales
2. Average Sales
3. Transaction Count

## Process

- Opened the Sample Superstore dataset in Microsoft Excel.
- Created a separate Summary sheet.
- Used Excel formulas to calculate Total Sales.
- Used the AVERAGE function to calculate Average Sales.
- Used the COUNTA function to calculate Transaction Count.
- Manually verified all three KPI calculations.
- Formatted the summary sheet for clear presentation.

## Formulas Used

### Total Sales
=SUM(Sales_Column)
### Average Sales
=AVERAGE(Sales_Column)
### Transaction Count
=COUNTA(Order_ID_Column)-1
## Result

The Summary sheet contains:

Total Sales
Average Sales
Transaction Count

All three calculated values were manually verified against the dataset.
